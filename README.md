# Yoshino River Paddle Tours

https://kawaasobi.com/sup のページをリニューアルした、高知・吉野川のSUP（リバーサップ）ツアーのLP（ランディングページ）を作成してください。

元ページの情報・要件：
・タイトル：高知・吉野川 リバーサップ体験ツアー（ガルバンゾ / Galbanzo）
・コース：ミニ！ツーリング 1.5km（初心者・ファミリー向け、8歳頃から）
・料金：5,000円 / 1人（Web特別・直前価格、前日20時までキャンセル無料）
・開催時間：午前便 9:45発 / 午後便 13:30発（集合は各時間の前）
・アピールポイント：
  - 清流ランキング1位の吉野川、エメラルドグリーンの綺麗な水（塩水じゃないからサラサラ）
  - 大豊ICから車で約15分、高松空港から約90分
  - 施設（ベース）が川の真横！移動が少ない（高知県長岡郡大豊町西土居1番地）
  - 初心者安心：20分のレッスン付き、泳げなくてもライフジャケット着用
  - 安全実績：JRCA公認インストラクター、27年間リバースポーツ無事故、各種保険加入
  - 楽しみ方：のんびり川下り、岩からの飛び込み、2人乗り、写真撮影（スタッフ撮影データの購入可）、スマホ持ち込み案内
  - 難しそうな方向けにパックラフトへの変更も可能
・ツアーの流れ：集合・準備運動・レッスン（10-20分）→ 浮く練習・レスキュー練習 → 出発・川下り → 飛び込み・自由時間（約40分）→ ゴール・写真確認
・持ち物＆レンタル：
  - 無料レンタル：ヘルメット、ライフジャケット、パドル、リーシュコード等
  - 有料レンタル：ウェットスーツ（500円、夏期は熱中症防止のため非推奨）、レンタルシューズ（300円）
  - 参加者用意：水着/濡れてもいい下着、濡れてもいい靴、化繊Tシャツ/ラッシュガード、日焼け止め、飲み物等
・予約・決済：
  - 公式LINE予約（空き状況の確認、直前予約）
  - 決済方法：PayPay、楽天Pay、現金
  - 当日の流れと注意事項（集合時間、更衣室・鍵付きロッカー完備、スマホ落下防止など）

モバイルファーストで洗練されたアウトドア・アクティビティLPとして、予約導線（LINE予約・空き状況確認）がスムーズで魅力が伝わるデザインに仕上げてください。
